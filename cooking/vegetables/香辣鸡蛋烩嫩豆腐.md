# 麻婆鸡蛋蒸豆腐

## 状态与适用条件

- **状态：待验证**；2026-11-05 改为优先考虑省事的电饭煲同煮方案，未收到实做反馈。
- **设备**：带蒸架的电饭煲、可以放入蒸架的耐热陶瓷碗或不锈钢碗，另备一个耐热盘子松盖防滴水。
- **食材**：嫩豆腐 300–400 g，一盒；鸡蛋 2 个；好人家麻婆豆腐调料（80 g/袋）。
- **份量**：1–2 人份，直接拌新煮的米饭。

## 成品目标

麻辣、鲜香、软嫩，类似麻婆豆腐与蒸蛋的混合物。**不要求豆腐完整、卖相整齐**；蒸久后鸡蛋可能偏老，优先保证同锅完成、无需炒锅、不勾芡。

## 原料

| 食材 | 用量 |
| --- | ---: |
| 嫩豆腐 | 350 g（300–400 g 皆可） |
| 鸡蛋 | 2 个 |
| 好人家麻婆豆腐调料 | 25–30 g |
| 水 | 20 ml |
| 香油 | 5 ml（可省略，出锅后加） |
| 大白菜 | 50–80 g（可省略） |

包装标示 80 g 调料含钠 4580 mg，使用 30 g 对应约 1718 mg 钠（不含其他原料），不再加盐、生抽或蚝油。此食品的标签标注较高的钠含量，不建议一次使用整包。

## 前处理

1. 米饭按平时比例淘洗、加水。
2. 嫩豆腐直接倒入耐热碗，用勺子压碎，不焯水。
3. 加 2 个鸡蛋、25–30 g 麻婆豆腐调料、20 ml 水，用勺子拌匀。若想放白菜，切碎 50–80 g 拌入。
4. 碗口松松盖一只耐热盘子防止蒸汽冷凝水大量进入；**不要密封**。

## 烹饪流程

1. 将蒸架放入装好米和水的电饭煲，耐热碗放蒸架上。确认碗不会接触加热底盘、顶住锅盖或阻挡蒸汽通路。
2. 开启日常正常煮饭档，通常约 25–40 分钟（依设备和米量波动），与米饭一起蒸。
3. 煮饭结束后检查碗中央鸡蛋是否完全熟透，无流动生蛋液。更可靠的安全判据是混合物中心温度达到 **74°C**；如未熟，再补蒸 5–10 分钟，直到达到标准。
4. 出锅后按需拌入 5 ml 香油，直接拌饭。

## 关键判断点

- **安全**：必须使用可蒸煮的耐热容器；不可用未知耐热等级的普通塑料盒，不可密封。
- **不要加太多水**：嫩豆腐与白菜本身会出水，首次从 20 ml 额外水开始。
- **蒸蛋口感**：和米饭同程蒸可能导致鸡蛋略老或有气孔，但流程最简；若不能接受，后续再调整加入时机。
- **确保熟透**：豆腐鸡蛋混合物的中心熟化速度受容器直径、厚度和电饭煲程序影响；不能只按米饭熟没熟判断。
- **咸度**：麻婆调料本身有明显盐分，不额外加咸味调料。

## 可变变量

- 豆腐量 300–400 g：优先保持调料 25–30 g；若首次偏咸，下一次降到 20–25 g。
- 白菜 50–80 g：切碎与豆腐同蒸，软烂但省事；不建议同蒸大量生菜。
- 鸡蛋 2→3 个：更容易形成有凝固感的结构，但蒸得太久也更容易变老；需重新验证。
- 追求更省事：香油和白菜均可省略。
- **单独炒锅版本**：详见本文件此前的 Git 历史版本；当前推荐先试无需炒锅的蒸制方式。

### 2026-11-05 — 电饭煲同蒸方案（当前推荐）

**固定条件**
- 嫩豆腐 350 g、鸡蛋 2 个、麻婆调料 25–30 g、水 20 ml；
- 带蒸架电饭煲，耐热碗。

**本次变量**
- 取消煎鸡蛋、炒料、炒白菜、勾芡；原料混在碗中直接蒸，与煮饭同步。
- 允许豆腐碎裂、鸡蛋略老，以减少操作。

**结果**
- 尚未实做；熟化时间、出水量、咸度和鸡蛋口感均待验证。

**结论**
- 不标记为稳定配方；优先验证电饭煲一次煮饭能否将碗中心蒸熟，之后再微调调料和水量。
